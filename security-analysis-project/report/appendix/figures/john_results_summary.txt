### Strategic Analysis

#### Why Attack Was Highly Successful:
1. **No Salt Protection**: NTLM hashes vulnerable to dictionary attacks
2. **Weak Password Selection**: Users chose common dictionary words
3. **Single Iteration**: No key stretching increases attack speed
4. **Rockyou Wordlist Coverage**: Contains most common passwords

#### Smith Hash Analysis:
- Resisted all attack methods (dictionary + rules + incremental)
- Likely uses non-dictionary password or complex character combinations
- Represents the 14% of passwords that require more intensive methods

#### Resource Management:
- CPU usage remained moderate throughout all phases
- No system overheating detected
- Excellent ROI: 86% success in <10 minutes total runtime

### John the Ripper Configuration Used:
- **Format**: --format=NT (NTLM hash detection)
- **Algorithm**: MD4 128/128 ASIMD 4x2 (ARM SIMD optimization)
- **MKPC**: 4096 (Most Keys Per Crypt for optimal performance)
- **Wordlist**: /tmp/rockyou.txt (decompressed from gzip)
- **Rules**: Default mangling rules + best64 optimized rules
- **Time Limits**: Applied to prevent excessive resource consumption
