# Security Policy

## Responsible Disclosure

If you discover a vulnerability, please:

1. Do not disclose publicly or in issues.
2. Email the maintainer privately at [email], including a minimal reproduction if possible.
3. Allow a reasonable time window for remediation before any public discussion.

Only test within the provided `lab/` environment. Do not target real services or third parties.

## Scope

- In-scope: Code and configurations within this repository and the `lab/` sandbox.
- Out-of-scope: Any external systems, networks, or services.

## Safe Harbor

Good‑faith security research conducted within the lab environment and following this policy will be appreciated and credited in release notes as appropriate.
