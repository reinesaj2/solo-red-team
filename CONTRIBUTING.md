# Contributing

This project is for educational and demonstration purposes only. All contributions must adhere to ethical guidelines and be limited to the local lab environment.

## Ethics & Guidelines

- Only run tools against the `lab/` sandbox; never target real services.
- Do not submit real credentials, tokens, or sensitive data in any form.
- Prefer adding simulation/dry‑run modes for potentially impactful scripts.
- Ensure evidence committed under `evidence/` is sanitized; raw artifacts must not be committed.
- Follow clear docstring format: """Purpose, Usage, Example""".

## Development

- Use Docker for local testing per `lab/README.md`.
- Keep scripts idempotent and rate‑limited by default.
- Submit small, focused pull requests with context.
